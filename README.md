# ELV-Language
This project might be a little ambitious, but I believe that I can do it

I'm going to design this as a pretty simple language made in C

In this language, I want Auto memory manegment and simple key words, Kind of like lua

Wanted keywords = {
    Func,
    if + then + elseif
    For,
    while,
    true + false,
    Tables Starting at 0 (Simple tables, like {1,2,3,"F"}, maybe something like {"G";123,"FSS"}, depending on the project diffifulty)
    log("No %s or anything like that to combine")
    ~ (for comments) + |~ and ~| (for multi line commets)
}


Wanted Features = {
    ** for Powers,
    // for sqrt
    Maybe more if i can think of them
}
